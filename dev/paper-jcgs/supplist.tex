{\large\bf SUPPLEMENTARY MATERIAL}
\end{center}

\begin{description}
\item[Supplement:] Details of the simulation studies (runs to
convergence, stress grid, calibration), a Gaussian check of the
blocked-sampler comparison, the random-intercept-only fits of the real
data, and a table mapping each result to the script that reproduces it
(PDF).
\item[Code archive:] Source of the R package \texttt{jmjax} at release
0.3.0 \citep{jmjax}, which implements the method, with the scripts and
result files that reproduce every table and figure and a README mapping
each result to its script (zip file). The package is also available at
\url{https://github.com/jmjaxmaintainer-jpg/jmjax}.
\end{description}

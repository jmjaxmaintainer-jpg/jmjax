Generative AI tools were used in this work. Anthropic's Claude was used to
help write and check analysis code, to search and summarize the
literature, and to draft and revise the manuscript under the author's
direction; OpenAI's ChatGPT was used to review drafts; Google's Gemini was
used to summarize one reference. The author designed the study, ran all
computations, checked the results and claims against the code and its
output, and takes full responsibility for the content.

\section*{Data availability statement}\label{data-availability-statement}

The \texttt{aids} and \texttt{pbc2} data are distributed with the R
package JMbayes2 \citep{jmbayes2}, the \texttt{Orthodont} data with nlme
\citep{pinheiro2000}, and the toenail data with HSAUR3
\citep{hothorn2014}. The simulated data are generated by the scripts in
the supplementary code archive.
